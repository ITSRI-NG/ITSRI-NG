# ITSRI: Innovators in Action 🚀


The official landing page for the **IT Society of Royal Institute (ITSRI)**. This project is a highly interactive, visually striking, single-page web application designed to showcase the society's vision, core values, upcoming activities, and leadership team. 

The website features a modern **3D Glassmorphism** aesthetic, driven by interactive mouse-tracking effects, custom scroll animations, and a dynamic HTML5 Canvas particle network background.

## ✨ Features

- **Interactive 3D Glassmorphism:** Cards and panels tilt and react in 3D space based on mouse cursor movement, complete with dynamic lighting glares.
- **Dynamic Particle Network:** A custom HTML5 Canvas particle system running in the background, drawing connecting lines between nodes based on proximity.
- **Fluid Blob Animations:** CSS-animated gradient blobs that provide depth and a modern aesthetic to the dark UI.
- **Scroll-Triggered Animations:** Elements smoothly reveal themselves as the user scrolls down the page using the Intersection Observer API.
- **Fully Responsive:** Seamlessly adapts to mobile, tablet, and desktop viewports with a custom mobile navigation menu.
- **No Build Tools Required:** Utilizes Tailwind CSS via CDN for rapid styling without the need for a complex Node.js build pipeline.

## 🛠️ Technologies Used

- **HTML5:** Semantic markup and structure.
- **CSS3 / Tailwind CSS:** Core styling, fluid typography, and utility classes.
- **Vanilla JavaScript (ES6):** DOM manipulation, 3D tilt physics, canvas particle rendering, and scroll observers.
- **Font Awesome (v6.4):** Iconography used throughout the UI.
- **Google Fonts:** 'Space Grotesk' for striking headings and 'Inter' for clean, readable body text.

## 🗂️ Project Structure / Sections

1. **Hero Section:** High-impact landing area with the society's motto and 3D logo.
2. **Strategic Direction:** Outlines the Vision and Mission of ITSRI.
3. **Core Values:** Highlights foundational principles (Innovation, Integrity, Collaboration, Leadership, Excellence, Creativity).
4. **Core Activities:** Details on Coding Workshops, E-Sports, and Hackathons.
5. **Leadership:** Showcases the Teacher in Charge (Mr. Janidu Lankage) and the student Executive Committee.
6. **Manual Download:** A dedicated portal to download the official ITSRI society guidelines.
7. **IT Day:** Information regarding the annual exhibition and innovation showcase.
